KVKK Aydınlatma Metni

Navizban, 6698 sayılı Kişisel Verilerin Korunması Kanunu (KVKK) kapsamında:

  • Konum veriniz yalnızca tren konumunuzu haritada göstermek için kullanılır
  • İzin vermeniz durumunda, anonimleştirilmiş tren konumu veriniz diğer kullanıcıların bekledikleri trenin varış süresini görmesi için paylaşılır
  • Paylaşılan veri yalnızca "hangi duraktan hangi durağa giden trende kaçıncı dakikadasınız" bilgisidir, ham GPS veriniz paylaşılmaz
  • Hiçbir kişisel bilginiz (isim, e-posta, telefon) toplanmaz veya paylaşılmaz
  • Verileriniz yalnızca yolculuk süresince geçici olarak tutulur, yolculuk sonunda silinir
  • Dilediğiniz zaman ayarlardan konum paylaşımını kapatabilirsiniz

🌐 navizban.xyz Domain Kurulum Rehberi

📋 Adım Adım: GitHub Pages'i kendi domaininize bağlama

  1. GitHub Pages'i etkinleştirin: Reponuzda Settings → Pages bölümüne gidin. "Source" olarak Deploy from a branch seçin, branch olarak main ve klasör olarak /docs seçin.
  2. Custom domain girin: Aynı sayfada "Custom domain" alanına navizban.xyz yazın ve "Save" butonuna tıklayın. GitHub size DNS kayıtlarını gösterecektir.
  3. Cloudflare DNS ayarları: Cloudflare Dashboard'da navizban.xyz domaininize gidin. DNS ayarlarına aşağıdaki kayıtları ekleyin: Tür: CNAME | Ad: @ | Hedef: araswqm.github.io | Proxy: DNS only Tür: CNAME | Ad: www | Hedef: araswqm.github.io | Proxy: DNS only
  4. Cloudflare SSL/TLS ayarı: SSL/TLS bölümünden "Full (strict)" seçeneğini seçin. Böylece HTTPS otomatik olarak çalışacaktır.
  5. Bekleyin: DNS değişikliklerinin yayılması 1-10 dakika sürebilir. GitHub Pages sayfasında "DNS check successful" yazısını görmelisiniz.
  6. Enforce HTTPS: GitHub Pages ayarlarında "Enforce HTTPS" kutucuğunu işaretleyin.

📌 Önemli Notlar

  • Cloudflare'de Proxy (turuncu bulut) değil, DNS only (gri bulut) kullanmalısınız. Aksi halde GitHub Pages çalışmaz.
  • GitHub Pages ayarlarında "Custom domain" alanını boş bırakmayın, aksi halde domain bağlantısı kopsa bile GitHub Pages çalışmaya devam eder.
  • Namecheap'te nameserver'ları Cloudflare'in verdiği nameserver'lara yönlendirdiğinizden emin olun.
  • APK dosyalarını GitHub Releases üzerinden yayınlayabilir ve bu sayfadan link verebilirsiniz.
